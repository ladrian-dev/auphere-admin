# Prototipos (spec 017)

Cada iteración empieza aquí: una story por pantalla, montada con los bloques
del sistema de diseño y copy real en español, revisada en Storybook con el
addon de accesibilidad en modo error. No importa nada de `apps/console`
(ni i18n ni router): es la forma de la pantalla, no la pantalla.

El owner aprueba el prototipo antes de que se escriba código de la consola;
la aprobación y la captura quedan en `specs/017-…/evidence/iteracion-N.md`.
Cuando la pantalla real existe, el prototipo se conserva como referencia de
diseño hasta que la spec se cierra, y entonces se retira.
